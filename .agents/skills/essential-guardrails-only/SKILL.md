# 최소 운영 규칙

This repository-local version makes the workflow portable. Use the host global skill when available; do not depend on personal tools to execute this repository.

Continue authorized reversible work without repeated confirmations. Keep exact checks for target identity, secrets, public file scope, source/timing integrity, destructive paths, recovery and duplicate publication. Use aggregate visual judgment and reasonable timing tolerance for non-safety quality differences.

Before a public commit, inspect the staged files and exclude recordings, raw evidence, credentials, private runtime and model weights. An authorization to publish code is not authorization to upload a video or send comments.

Before moving/deleting a directory, verify its resolved source/destination stay within named roots. Prefer a recoverable archive for obsolete experiments. Keep one owner and exact process ID for long-running renders; do not restart or duplicate an active job. Run checks relevant to changed behavior and stop repeating them once they pass without new concerns.
