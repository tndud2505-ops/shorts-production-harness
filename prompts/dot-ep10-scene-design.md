# Dot 협업 요청 · ep10 새 시나리오

아직 검토 중인 대본/연출 제안이다. 먼저 사용자 피드백을 반영한 최신 버전을 전달한다. ep08 개선 요청 및 별도 ep09 기획과 혼동하지 않는다.

---

이번에는 새 영상 기획을 같이 진행해줘. README.md, wiki/WORKFLOW.md, wiki/episodes/ep10.md와 episodes/ep10-agentic-scope/scene-plan.json을 먼저 읽어줘.

핵심은 “에이전트라는 이름보다 사람이 하던 어떤 업무와 판단을 줄일지 구체적으로 정하고, 직접 검토·수정해본 작은 자동화부터 공용화하자”는 개발자의 경험이야. 공식 에이전트 정의를 가르치거나 상사를 무능한 악역으로 그리는 영상이 아니야.

약 90초를 목표로 하되 현재 음성 실측은 없어. 세 가지 범주를 강의하듯 길게 설명하지 말고, 골 순간과 평범한 대화에 똑같이 느리게 버튼을 적용하는 짧은 예시로 장면의 의도가 다름을 보여줘. 스포츠=무조건 슬로모션, 예능=슬로모션 금지라는 규칙을 만들면 안 돼.

먼저 장면 01(막연한 주문), 03(같은 버튼·다른 맥락), 08(구체적인 업무 질문)의 정지 시안을 만들어줘. 이 구간들이 읽히는지 확인한 뒤 나머지 장면과 모션으로 확장해줘. 기존 주인공을 쓰는 안을 바탕으로 하되 ep08 구도를 그대로 복제할 필요는 없어.

`node scripts/scene-assets.mjs --episode ep10-agentic-scope`로 계획을 확인하고 부족한 SVG/포즈/소품을 찾아줘. 기존 3묶음, 변형 3묶음, 신규 3묶음으로 정리돼 있어. 없는 그림을 기존 서버·상자·웃는 얼굴로 억지 대체하지 말아줘. 새 캐릭터가 필요하면 대화용 중립 인물 정도로 최소화해줘.

수정 범위는 ep10 전용 구현과 자산, scene-plan.json, 검토 결과 문서야. 새 소스는 video/src/ep10/, 새 자산은 video/public/illustrations/ep10/에 모아줘. ep08/ep09, 공통 주인공 기본형, 음성 파이프라인, 대본 원본 wiki/episodes/ep10.md는 직접 고치지 말고 변경이 필요하면 제안해줘. 등록이 필요할 때만 Root.tsx에 추가하고 기존 composition을 유지해줘.

현재 ep10은 새 composition/runtime이 없어서 기존 production.mjs preview 명령으로 바로 렌더할 수는 없어. 새 정지 시안 composition부터 구현해줘. 임시 모션 길이는 임시라고 보고하고 음성에 맞췄다고 말하지 말아줘. TTS는 여기 로컬에서 확정 대본으로 만들 거야.

전달물: 대표 시안, 자산 포즈/유형표, 바꾼 이유, 부족한 자산/의미상의 질문, 재현 명령. Git 원격 쓰기 권한과 반영 요청이 있을 때만 공유 브랜치로 전달하고, 영상 업로드·댓글 작성은 하지 마.
