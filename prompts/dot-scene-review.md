이 저장소의 영상 제작 작업을 이어서 진행해줘. 먼저 README.md → AGENTS.md → wiki/WORKFLOW.md → wiki/PATTERNS.md → wiki/episodes/ep08.md → wiki/OPERATIONS.md 순서로 읽어줘. 관련 로컬 스킬은 필요한 것만 사용해줘.

이번 작업은 **ep08 전체 영상에서 말하는 내용과 맞지 않는 캐릭터 표정·이모티콘·소품·말풍선·등장/퇴장 시점을 수정하는 것**이야. 단순히 예쁘게 꾸미는 것보다 “이 문장에서 이 그림이 왜 나오는가”를 이해해줘. 이번 SVG/Remotion 연출은 앞으로 만들 여러 방식 중 하나야. 공통 절차를 이번 전환 방식에 고정하지 말아줘.

1. 전체 대본을 읽고 핵심 메시지와 이야기 순서를 이해해줘. 사이트 홍보가 아니라 운영하며 알게 된 점과 실제 수익을 소개하는 영상이야. 서비스 링크는 내가 댓글에 달 거야.
2. `node scripts/production.mjs scenes`로 실제 문장 시각을 보고, ep08 문서의 6가지 검토 후보부터 확인해줘. `still --scene ID --sentence N --progress 0.1`/`0.5`/`0.9`와 짧은 구간 영상으로 문장 경계도 봐줘. 추측만으로 수정했다고 하지 말아줘.
3. 우선 `used-pivot`/`traffic`의 너무 늦는 등장, `earnings`에서 실망 포즈를 웃게 만드는 말하기 입, `jira` 생각풍선의 문장 불일치, `emotown-stop`의 3D 비교 잔류와 “다시” 표현을 검토해줘. `lessons`의 상자와 `ending`의 서버는 대사 의미에 맞는지 판단해서 정리해줘. 재사용 자산이라는 이유만으로 그대로 두지 말아줘.
4. 승인된 캐릭터 기본형 `video/public/characters/reference-v5/neutral.svg`의 머리·얼굴·짧은 몸 비율을 유지해줘. 기본형 승인이 모든 변형 포즈 승인이라는 뜻은 아니야. 팔·손·소품 연결을 고치고 포즈표와 실제 장면을 비교해줘. 첫 장면부터 같은 주인공을 유지하고 기존 보조 이모티콘은 내용에 맞을 때 활용해줘.
5. 그림만 바뀌면 기존 음성과 문장 타이밍을 유지해줘. 문구나 뜻을 바꿔야 한다면 episode.json을 원본으로 다루고, 이해되지 않는 연결·동기·인과는 나에게 질문한 뒤 확정해줘. Jira는 멋있겠다는 추상적 아이디어에서 출발해 실사용을 증명하지 못한 경험이야. 다운로드 0으로 원인을 단정하지 마. 카톡/배달 용기 스티커는 사용 목적의 예시이고 실제 구현 기능이 아니야.
6. 풍선 꼬리는 실제 머리 위치에서 이어지고 자료·자막을 가리지 않게 해줘. 숫자와 범위를 유지해줘. 약 1만원 수익, 150만원 구독비, 6만원 도메인, 서버 현재 0원/향후 월 40달러, 마지막 구독비 기준 −149만원 4초 무음이야.
7. 수정 후 타입 검사, 변경된 장면 프레임/짧은 영상, SVG 재출력과 포즈표 갱신을 해줘. 현재 공개 환경에는 원본 음성과 개인 캡처가 없어. 이 경우 무음 전체 검토본과 코드·검토 결과를 전달해줘. 로컬 자산이 있는 환경에서만 선택된 `new-reference` 설정으로 유성 최종본을 출력해줘. 다른 목소리나 가짜 서비스 화면을 넣지 마.
8. 마지막에 바꾼 장면과 이유, 실제 확인한 내용, 남은 질문, 재출력 명령을 ep08 문서에 갱신해줘. 결과물 경로와 변경 요약을 알려줘. 영상 업로드·댓글 작성은 하지 마.

코드 위치: `video/src/ReferenceFullArt.tsx`, `video/src/components/ReferenceMascot.tsx`, `video/src/components/SvgBalloon.tsx`, `video/src/CleanRetrospectiveFilm.tsx`. SVG 원본은 컴포넌트이고 `video/public/illustrations/`는 재생성 가능한 출력이야.
