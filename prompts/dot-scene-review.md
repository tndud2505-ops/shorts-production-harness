이 저장소의 영상 제작 작업을 이어서 진행해줘. 먼저 Git의 현재 README.md → AGENTS.md → wiki/WORKFLOW.md → wiki/PATTERNS.md → wiki/episodes/ep08.md → wiki/episodes/ep08-2026-11-07-results.md → wiki/OPERATIONS.md 순서로 읽어줘. 관련 스킬은 필요한 것만 사용하고 `essential-guardrails-only`를 적용해줘. 최신 사용자 요청을 과거 실험·전달본보다 우선해줘.

이번 작업은 **ep08 전체 이야기와 맞는 실제 생성 PNG 캐릭터·소품·이모티콘을 사용하고 표정·말풍선·등장/퇴장 시점을 확인하는 것**이야. 승인된 생성 그림의 귀여운 외형과 품질을 기준으로 삼아줘. 기존 SVG를 PNG로 내보내거나 벡터로 다시 그리는 것만으로 최신 PNG 품질 요청을 충족했다고 하지 마. “이 문장에서 이 그림이 왜 나오는가”를 이해하고, 이번 방식을 앞으로 모든 영상의 형식으로 고정하지 말아줘.

1. **Git 읽기 → 파일 전달 → 로컬 비교·통합** 순서로 진행해줘. 이번 전달은 ZIP 또는 개별 파일과 변경 요약·출처·SHA-256으로 하고 커밋·push는 하지 마. Windows 통합 경로는 `C:/DeVelop/SHORTS/local/dot-handoff/2026-11-08/`이야. 받은 저장소 전체로 현재 작업 트리를 덮어쓰지 말고, 로컬 담당자가 변경 파일과 버전을 비교해 통합할 수 있게 해줘.
2. 보존된 `ep08-full-png-v10-silent-review.mp4`는 원본 v10이야. SHA-256은 `83d6de3e0c378f0988ac5d378ef85d149a1733bb2423933521008d43ca1595d7`, 168.4초·1080×1920/30fps·5,052프레임·H.264 영상만 있고 오디오는 없어. 실제 복구된 개별 PNG는 9포즈이며 10포즈표와 구분해줘. v10r은 v9 소스와 9포즈에 새 중립 포즈·소품을 더한 별도 재구성본이고 시각 검토가 미완료야. v10 원본 소스·동일 영상으로 표시하거나 과거 v10 QA를 v10r·현재 코드 검증으로 옮기지 마.
3. Windows helper는 `os.setxattr` 오류로 실패했고 이후 주 작업자가 브라우저로 4개 파일을 받았어. 별도 Dot WSL 전달 7개는 `\\wsl.localhost\Ubuntu\root\dot-handoff-ep08-2026-11-07`에 보존해줘. 이미 받은 파일은 인계 문서와 수신 목록을 먼저 확인하고, 기존 원본을 이동·덮어쓰기·삭제하지 마.
4. 전체 대본을 읽고 핵심 메시지와 이야기 순서를 이해해줘. 사이트를 운영하며 알게 된 점과 실제 수익을 소개하는 영상이고 서비스 링크는 내가 댓글에 달 거야. 무료 SVG는 광고 수익을 기대한 사이트야. 3D 비교는 개인 판단이고 카톡/배달 용기 스티커는 사용 목적의 예시야. Jira 다운로드 0으로 실패 원인을 단정하지 마. 이해되지 않는 연결·동기·인과는 나에게 질문한 뒤 확정해줘.
5. 복구된 실제 PNG와 승인된 생성 그림을 먼저 확인하고 캐릭터·소품·리액션 유형별로 원본과 출처를 관리해줘. 새로 생성한 중립 포즈나 소품은 복구 원본과 구분해줘. 같은 주인공의 얼굴·머리·짧은 몸 비율과 팔·손·소품 연결을 살피고 포즈표와 실제 장면을 비교해줘. 기본형 승인은 모든 포즈 승인이 아니야. 정확한 글자·금액·차트선은 편집 가능한 코드층을 써도 돼. PNG 고정 입모양과 레이어 모션을 음소 립싱크라고 부르지 마.
6. 기존 v6의 6가지 후보와 Dot의 후속 보고를 비교해줘. `used-pivot`/`traffic`의 등장, `earnings` 표정, `jira` 생각풍선, `emotown-stop` 비교 잔류와 “다시”, `lessons` 생활 속 필요, `ending` 비용과 직접 사용의 구분을 해당 버전의 실제 프레임으로 확인해줘. 현재 Remotion 어댑터에 통합된 경우 `node scripts/production.mjs scenes`와 `still --scene ID --sentence N --progress 0.1`/`0.5`/`0.9`, 필요한 짧은 구간으로 문장 경계를 봐줘. 기존 코드의 출력이 원본 v10이라고 가정하지 마.
7. 그림만 바뀌면 기존 선택 음성과 문장 타이밍을 유지해줘. 문구를 바꾸면 `episode.json`에서 시작해 생성과 미리보기까지 반영해줘. 약 1만원 수익, 과거 잔액 4,591원과의 구분, 5개월 구독비 150만원, 도메인 6만원, 서버 현재 0원/쿠폰 이후 월 40달러, 초기 eCPM 2천–3천원과 두 광고 단위 261/117원을 유지해줘. 마지막은 도메인을 제외한 구독비 기준 −149만원, 약 4초 무음이야. 풍선 꼬리는 실제 머리에서 이어지고 자료·자막을 가리지 않게 해줘.
8. 변경에 맞는 최소 타입·자산 확인과 변경 장면의 실제 프레임/필요한 짧은 영상, PNG 포즈표를 확인해줘. 과거 Dot 보고, 이번에 직접 확인한 사실, 미검토 구간을 나눠 적어줘. 현재 주 작업자가 진행하는 유성 렌더를 중복 실행하지 말고, 완료·실제 음성 동기는 담당자의 출력 검증 후 기록해줘. 공개 환경에는 개인 음성·원본 캡처가 없으므로 필요한 검토는 무음으로 하고 다른 목소리나 가짜 서비스 화면으로 대체하지 마. 로컬 유성 통합에는 기존 `new-reference` / `youtube-XIbUKM89IJI` 설정을 유지해줘.
9. 바꾼 장면과 이유, 실제 확인 범위, 남은 질문, 결과물 경로·해시·재출력 명령을 전달해줘. 문서는 기존 사용자 의도·숫자·출처를 보존해 병합할 수 있게 해줘. **영상·개인 음성은 업로드하지 마. 원본 캡처·비공개 다운로드 링크도 공개하지 말고 댓글을 작성하지 마.** 소스·PNG·문서는 사용자가 지정한 로컬 인계 경로로 전달해줘.

기존 코드 탐색 시작점은 `video/src/ReferenceFullArt.tsx`, `video/src/components/ReferenceMascot.tsx`, `video/src/components/SvgBalloon.tsx`, `video/src/CleanRetrospectiveFilm.tsx`야. 실제 PNG 어댑터·자산 경로와 통합 여부를 현재 파일에서 확인해줘. 과거 SVG 원본과 출력은 이전 영상 재현용 이력으로 보존하고 새 생성 PNG의 출처로 표시하지 마.
