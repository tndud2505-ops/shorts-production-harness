# PNG illustration library

The EP09 film uses generated illustrations received from Dot, without redrawing them as SVG.

- `characters/dot-v10/`: nine recovered original poses, preserved byte for byte.
- `characters/dot-v10r/neutral.png`: regenerated neutral pose from the separately labeled v10r reconstruction. It is not the lost v10 neutral original.
- `props/dot-v10r/props-atlas.png`: generated prop sheet from that reconstruction; rendered through isolated CSS crop viewports.
- `reactions/ep09/`: three existing generated reaction illustrations, unchanged.
- `dot-manifest.json`: asset hashes and provenance.

EP09 is a new composition using these assets. EP08 final uses the preserved v10 video directly and does not use v10r to recreate its frames. All titles and subtitles remain editable text. PNG mouths are fixed; movement is pose changes and layer transforms.

The abandoned raster-export trial of older SVG artwork is archived locally; it is not the approved PNG visual source. Older SVG components remain intact for historical video reproduction.
