## 기록 원칙

- 공통 절차는 WORKFLOW 한 곳, 코드 사용법은 OPERATIONS 한 곳에 둡니다.
- 특정 색상·캐릭터·전환·음성은 해당 방식이나 에피소드에 둡니다. 새 영상에 자동 상속하지 않습니다.
- 결정은 `요청/근거 → 선택 → 적용 범위 → 남은 문제`로 짧게 기록합니다. 대화 전문과 같은 결론을 반복해서 덧붙이지 않습니다.
- 완료·제안·검토 후보를 구분합니다. 캐릭터 기본형 승인과 모든 포즈 승인도 별개입니다.
- 파일 이동 뒤 실제 실행과 문서 링크를 확인합니다. 과거 실험 복구용 자료는 공개 저장소 밖에 둡니다.
