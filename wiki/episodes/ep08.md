# ep08 · AI로 사이트 6개를 만들고 알게 된 것

방식: [illustrated-developer-story](../patterns/illustrated-developer-story.md). 현재 상태: v6 전체본 로컬 보존, 장면별 시각 개선은 Dot 작업 대기. **이 사례를 앞으로 만들 모든 영상의 형식으로 고정하지 않습니다.**

## 의도와 이야기

중심은 “AI로 서비스를 만들어 운영하며 알게 된 점과 실제 수익”입니다. 서비스는 경험을 설명하는 사례이고 링크는 사용자가 댓글에 답니다. 현재 범위는 30초가 아니라 전체 이야기입니다.

> 재밌거나 멋져 보이는 아이디어만으로는 사용할 이유를 설명하기 어려웠다. 실제 생활의 필요와 연결되는지, 계속 운영할 비용을 감당할 수 있는지까지 생각하게 됐다.

자동차 SW 개발자 소개 → 다섯 달 동안 사이트 6개+별도 업무 앱 1개 → 무료 SVG 운영·생성 비용·쓰임새 문제 → 3D/생활 속 쓰임의 맥락 → Jira 아이디어·홍보·다운로드 0 → 중고·주식의 실제 필요 → AWS/Docker 운영 → 방문 통계·광고 단가 → 수익·비용·앞으로의 기준 순서입니다.

## 사용자가 확인한 의미

- SVG는 무료 배포로 방문자를 모아 광고 수익을 기대한 사이트입니다. 유료 SVG 판매가 아닙니다.
- “3D 모델도 파는 시대”는 명확한 목적 없는 SVG의 경쟁력이 부족하다고 느낀 개인 판단입니다. SVG 자체가 쓸모없어졌다는 주장이 아닙니다.
- 카톡에서 쓰기, 배달 용기에 인쇄 스티커 붙이기는 **구체적 쓰임새의 예시**입니다. 운영했던 인쇄 서비스나 실제 기능처럼 묘사하지 않습니다.
- Jira 앱 역시 “있으면 멋있겠다”는 추상적 아이디어에서 시작했고 실제 쓰임을 증명하지 못했다고 돌아봅니다. 자동 홍보 후 다운로드 0은 결과이며, 원인을 입증한 수치가 아닙니다.
- 중고 매물 모아보기와 원하는 차트 종목 찾기에는 실제 필요가 있었습니다. 서버 부담에 따른 중고 수집 범위 축소, 부모님에게서 얻은 주식 아이디어를 유지합니다.
- 광고 요청≠페이지뷰, 일부 행≠하루 전체 합계, GA≠완벽한 사람 집계입니다. 광고 단가 하락을 제공자의 의도적 정책으로 단정하지 않습니다.
