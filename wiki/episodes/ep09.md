# ep09 · AI로 협업이 안 되는 진짜 이유

현재본: **v2 PNG / 쉬운 디버깅 에이전트 예시**. 기존 v1 전체본은 보존했다. 이 문서와 episode.json이 최신이며, 예전 제어 모듈 구조 변경 예시는 사용하지 않는다.

## 이어받은 사용자 수정

「AI 협업 태도 시나리오 이어쓰기」 채팅에서 사용자는 SVG 대신 PNG를 유형별 폴더로 관리하고, 주는 쪽 예시를 쉽게 바꾸라고 요청했다. AI로 디버깅용 에이전트를 만들었다면 우리 장비의 여러 상황에서 직접 여러 번 시험하고 안 되는 부분을 고쳐야 한다. 반복 작업과 불필요한 호출도 줄여 받는 사람의 시간과 토큰을 아끼는 노력을 담는다.

AI가 '90%' 만든다는 말은 사용자의 완성도 비유다. 실제 측정치로 보이지 않게 대본에서는 '겉보기에는 거의 완성돼도'로 표현했다. 검토 시간 3배, 협업 0%, 팀원 5명처럼 근거 없는 수치 표시는 새 화면에서 쓰지 않는다.

## 이야기와 음성

개발자 소개 → 주는/받는 태도 → 디버깅 도구의 미완성 부분 → 우리 장비에서 반복 시험 → 시간·토큰을 아끼는 다듬기 → 받는 쪽의 평가 태도 → 각자도생 → 활용과 공동 개선 → 양쪽의 노력으로 마무리한다. 실제 특정 회사·장비·상사 사례를 재현하지 않는다.

- 대본 원본: [episode.json](../../episodes/ep09-ai-collaboration/episode.json)
- 읽기용 대본: [narration.txt](../../episodes/ep09-ai-collaboration/narration.txt)

## PNG 구현

Dot에서 전달된 실제 생성 PNG를 그대로 사용한다. `video/public/png/characters/dot-v10/`은 복구한 원본9포즈이며, `characters/dot-v10r/neutral.png`와 `props/dot-v10r/props-atlas.png`는 별도 재구성본에서 받은 생성 자산이다. v10 원본과 재구성 자산의 출처를 [manifest](../../video/public/png/dot-manifest.json)에 구분했다. 이 EP09는 해당 자산을 재사용한 새 구성이고 EP08 v10을 재현한 영상이 아니다.

이전 SVG를 PNG로 내보낸 시험 결과는 최종본에 사용하지 않는다. 같은 캐릭터를 좌우 역할과 상황별 포즈로 배치하며, 기존 리액션 PNG3종은 해당 문장 안에서 최대2.4초 표시한다. 주인공은 리액션 중에도 유지한다. 소품 시트는 각 셀 안에서 클리핑해 옆 그림이 새지 않게 한다. 제목·자막·정확한 글자는 코드층으로 유지하며 입모양은 고정이다.

## 재현

대본을 다시 바꾼 경우에만 먼저 아래 로컬 음성 명령을 실행한다. 현재 출력에는 이미 합성된 음성을 재사용한다.

```powershell
./scripts/run-qwen.ps1 --episode ep09-ai-collaboration --profile voices/profiles/youtube-XIbUKM89IJI.json --model models/Qwen3-TTS-12Hz-0.6B-Base --non-streaming-mode --temperature 0.45 --top-p 0.8 --seed 42
```

```sh
node scripts/refresh-preview.mjs ep09-ai-collaboration
node scripts/production.mjs render --episode ep09-ai-collaboration --output video/out/ep09-ai-collaboration-v2-png-final.mp4
python scripts/review_retrospective.py --episode ep09-ai-collaboration --video video/out/ep09-ai-collaboration-v2-png-final.mp4 --output-dir video/out/ep09-v2-review
```

이전 대본·런타임·자막·위키는 `local/backups/ep09-before-png-v2/`에 보존했다. 기존 MP4는 `video/out/ep09-ai-collaboration-final.mp4`이며 새 수정본과 구분한다.

## 최종 결과 · 2026-11-08

결과는 `video/out/ep09-ai-collaboration-v2-png-final.mp4`다. 115.366667초, 1080×1920/30fps, H.264/AAC48kHz이며 선택 음성을 1배속으로 사용한다. 타입 검사와 전체 영상·음성 디코딩을 통과했다. 12장면의 실제 MP4 표본과 디버깅/리액션 전환 31.8–36.2초의 0.4초 간격 표본을 확인했다. 주인공과 자막이 리액션에 가리지 않고 문장 변경에 따라 시험 장면으로 전환됐다. 검토 기록은 `video/out/ep09-v2-review/report.json`, `contact.jpg`, `debugging-transition.jpg`다. 모든 프레임의 연속 재생·휴대폰 실기기 검증은 수행하지 않았다.

SVG 래스터 시험 소스·출력은 `local/backups/ep09-svg-raster-trial/manifest.json`으로 복구 가능하게 분리했다. 선택 음성·MP4는 공개 저장소에 포함하지 않는다. EP08 v10 원본과 EP09는 각각 별도 결과물로 전달한다.
